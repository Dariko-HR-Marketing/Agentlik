# Agentlik ERP (Avenir OS Clone)

Professional darajadagi yaxlit ERP, CRM, Moliya, Loyihalar, HR va AI boshqaruv tizimi (Avenir OS kloni).

## 🚀 Texnologiyalar
- **Frontend:** React 18, TypeScript, Vite
- **UI/Dizayn:** Tailwind CSS (Dark/Light palette `#0d1117`), Lucide Icons
- **Backend muvofiqligi:** Avenir API v1 spetsifikatsiyasi (`/analytics`, `/crm`, `/finance`, `/projects`, `/people`, `/ai`)

## 📦 O'rnatish va ishga tushirish
```bash
npm install
npm run dev
```

## 🛠 Ishlab chiqarish uchun yig'ish (Production Build)
```bash
npm run build
```

## 🐳 Docker orqali ishga tushirish
```bash
docker compose up -d --build
```
